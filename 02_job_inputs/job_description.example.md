# Example Job Description

- Role: Junior Data Scientist
- Company: Example AI GmbH
- Location: Berlin, Germany
- Source: https://example.com/jobs/junior-data-scientist

## Responsibilities

- Build data analysis and machine learning prototypes in Python.
- Prepare, clean, and validate datasets for analytics and model training.
- Communicate findings to product and business stakeholders.

## Requirements

- Python, pandas, SQL, and scikit-learn.
- Basic understanding of model evaluation and data visualization.
- Clear communication in English; German is a plus.
