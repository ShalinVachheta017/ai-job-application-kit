# Truth & Quality Rules

Customize these rules for your own situation before generating applications.

1. Never claim a language level above your real level.
2. Never claim full-time professional experience unless it is true.
3. Keep thesis, coursework, internships, student jobs, freelance work, and personal projects clearly separated.
4. Do not invent tools, metrics, employers, job titles, publications, certificates, or production impact.
5. Use only bullets and facts that exist in `experience_bank.yaml`.
6. Keep the targeted CV focused: normally 2 experience blocks and up to 4 projects.
7. If the job requires a language level or work authorization you do not have, flag it before applying.
8. If the job says applications must go through a portal, do not draft an email application as the primary route.
9. Always check the tracker before generating a new application to avoid duplicates.
10. Always run a QA check before marking an application ready.
11. Match output language to the job description unless the user explicitly chooses another language.
12. State relocation and availability honestly.
